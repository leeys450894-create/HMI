Resume Inspection

ALPHA HMI - Glass Inspection Resume Feature
Date: 2026-07-03 Status: Phase 1~5, 7 Complete Author: LYS

1 Overview

Glass inspection is interrupted (NG, Cancel, crash, power-off) during N-Stick measurement loop. Resume Inspection saves progress per-stick and allows the next run to continue from where it stopped.

Before (AS-IS)

Stick 30 measurement in progress
Stick 15 interrupted by anomaly
Next run: starts from Stick 0 (all over again)

VS

After (TO-BE)

Stick 30 measurement in progress
Stick 15 interrupted by anomaly
Next run: resume popup -> starts from Stick 16

6 Atomic Save Mechanism

Crash-safe write strategy: temporary file write + NTFS atomic rename.

WriteToFile
(.ini.tmp)
➔
PathFileExists
verify success
➔
DeleteFile
(original)
➔
MoveFile
(tmp → original)
Safety: If WriteToFile fails, the original file is preserved. If MoveFile fails, falls back to CopyFile + DeleteFile(tmp).

7 SystemConfig.ini Options

[OPT_PARA]
USE_RESUME_INSPECTION=0    ; 0=OFF, 1=ON (Resume ON/OFF)
RESUME_EXPIRE_HOURS=0     ; 0=unlimited, 24=auto-discard after 24h

USE_RESUME_INSPECTION

  • 0 (OFF): Feature disabled, normal behavior
  • 1 (ON): Enable resume check on inspection start

RESUME_EXPIRE_HOURS

  • 0: No expiration (resume always available)
  • N: Discard resume info after N hours
