테스트 모드 (TEST MODE)

IDD_DLG_TEST_MODE - 수동 셀 이동 및 프로브 접촉 기능
Dialog ID: IDD_DLG_TEST_MODE (2006) 프로젝트: ALPHA HMI 작성자: LYS

1 개요

테스트 모드는 엔지니어가 Glass 그리드에서 셀을 수동으로 선택하여 스테이지/헤드 이동 및 프로브 접촉 동작을 실행할 수 있는 기능입니다. 자동 시퀀스를 실행하지 않고 디버깅 및 캘리브레이션 목적으로 사용됩니다.

MOVE (이동)

선택된 셀 위치로 스테이지 + 헤드 이동

PRE-CONTACT (사전접촉)

프로브를 사전 접촉 위치로 접근

CONTACT (접촉)

프로브 완전 접촉 (End + OD)

UNCONTACT (접촉해제)

프로브 후퇴

3 이중 구현 아키텍처

테스트 모드는 서로 다른 통신 경로를 사용하는 2개의 독립된 구현체가 존재합니다.

dfcRecipe DLL (IPC 방식)

CoreFunction/dll_Recipe/dfcRecipe/DlgTestMode.cpp

1 g_inRcpInfo에서 레시피 읽기 (DLL 내부)
2 위치 데이터를 VTM_RECIPE 공유 메모리에 패킹
3 WM_RECIPE_EVENT 메시지를 부모 윈도우에 전송
4 App 측 CRecipeEditMgr가 수신하여 모션 실행

Source/ALPHA (직접 호출 방식)

Source/ALPHA/DlgTestMode.cpp

1 CRecipeEditMgr에서 레시피 직접 읽기
2 프로세스 내에서 헤드 위치 계산
3 CMaintControlMgr 모션 API 직접 호출
4 즉시 동기 결과 반환 및 상태 업데이트
핵심 차이점: DLL 버전은 공유 메모리 + 윈도우 메시지(IPC)로 통신합니다. ALPHA 버전은 매니저 API를 직접 호출합니다(인프로세스). 두 방식 모두 동일한 모터 동작을 수행합니다.

5 테스트 모드 - 4가지 모드 (헤드 이동)

모드헤드 축Z 위치모션 API용도
0: Review Y1, Y2, X2 Z2 = ReviewZ
Z1 = SafetyZ2		 MoveCmdPosReview() 육안 검토 위치
1: WAD Y1, Y2, X2 Z2 = SpecZ
Z1 = SafetyZ2		 MoveCmdPosWAD() WAD 특성 측정 위치
2: Vision Y3, Y4, X3 Z1 = QualityZ
Z2 = SafetyZ1		 MoveCmdPosVision() 화상 검사 위치
3: Angle Y1, Y2, X2 Z2 = AngleZ
Z1 = SafetyZ2		 MoveCmdPosAngle() 시야각 측정 위치
2-헤드 페어링 로직: Y1/Y2 (또는 Y3/Y4)는 쌍(pair) 헤드입니다. 인접 셀 간 간격이 HeadGap보다 크면 두 헤드가 각각 다른 셀로 분리됩니다. 간격이 HeadGap 이하이면 두 헤드 모두 동일 셀 중심으로 수렴합니다.

6 DLL 공유 메모리 데이터 패킹

dfcRecipe DLL은 모든 위치 데이터를 VTM_RECIPE::m_sRunState 공유 메모리에 패킹한 후, 윈도우 메시지로 App에 신호를 보냅니다.

// S_RecipeRunState 구조체 패킹
m_dwData1 = M_CMD_TEST_MODE // 명령 ID (0x19)
m_dwData2 = 0=이동 | 1=사전접촉 | 2=접촉 | 3=접촉해제
m_dwData3 = m_nTestMode // 0~3 (Review/WAD/Vision/Angle)

// fData[] — double 정밀도 위치 데이터
fData[0] = Stick 인덱스   fData[1] = Cell 인덱스
fData[2] = StageY         fData[3] = StageR (회전)
fData[4] = CellX          fData[5] = CellY
fData[6] = Stick0 StageY   fData[7] = Cell 개수
fData[8] = ReviewZ        fData[9] = SpecZ
fData[10+] = 전체 Cell X 위치 (2-헤드 페어링용)

// nData[] — int 정밀도 (x1000 스케일)
nData[0] = QualityZ*1000   nData[1] = AngleZ*1000
nData[2] = OffsetY*1000    nData[3] = OffsetR*1000
nData[4] = HeadReviewY*1000
nData[5] = BackHeadGap*1000   nData[6] = FrontHeadGap*1000

// App에 신호 전송
::PostMessage(m_hWnd, WM_RECIPE_EVENT, M_RCP_TEST_MODE, sub_cmd);

8 프로브 접촉 메커니즘

접촉 위치 파라미터 (레시피 S_ContactPos)

파라미터변수명설명
대기 위치m_fReadyPos초기 안전 Z 높이
사전접촉 위치m_fPreContactPos접근 거리 (SPEED_HIGH로 이동)
최종접촉 위치m_fEndContactPos최종 접촉 깊이 (SPEED_LOW로 이동)
추가 ODm_fAddOD확실한 접촉을 위한 오버드라이브 거리

접촉 시퀀스

PRE-CONTACT (사전접촉)
▼
ProbeZ5 → 사전접촉위치
속도: HIGH (고속 접근)
OD: 0 (오버드라이브 없음)
▼
프로브가 표면 근처
(안전 접근 완료)
CONTACT (2단계 접촉)
▼
1단계: ProbeZ5 → 사전접촉위치
속도: HIGH (고속 접근)
▼
2단계: ProbeZ5 → 최종접촉위치 + OD
속도: LOW (정밀 접촉)
▼
프로브 접촉 완료
SACC 카운트 업데이트
UNCONTACT (접촉해제)
▼
ProbeZ5 → 후퇴
속도: HIGH (고속 후퇴)
이동량: PreContactPos 거리
▼
프로브 후퇴 완료
(안전 위치)
OCP 플랫폼: 모든 프로브 접촉 동작은 AXIS_PROBE_Z5로만 리다이렉트됩니다 (단일 프로브 갠트리). HMI 플랫폼은 Z1~Z5 5개 프로브를 사용합니다.
