TEST MODE

IDD_DLG_TEST_MODE - Manual Cell Move & Probe Contact
Dialog ID: IDD_DLG_TEST_MODE (2006) Project: ALPHA HMI Author: LYS

1 Overview

Test Mode allows engineers to manually select a cell on the Glass grid and execute stage/head movement and probe contact operations for debugging and calibration purposes, without running the full Auto Sequence.

MOVE

Stage + Head movement to selected cell position

PRE-CONTACT

Probe approach to pre-contact position

CONTACT

Full probe contact (End + OD)

UNCONTACT

Probe retraction

3 Dual Implementation Architecture

Test Mode has two separate implementations that work through different communication paths.

dfcRecipe DLL (IPC Approach)

CoreFunction/dll_Recipe/dfcRecipe/DlgTestMode.cpp

1 Read recipe from g_inRcpInfo (DLL-side)
2 Pack position data into VTM_RECIPE shared memory
3 Post WM_RECIPE_EVENT to parent window
4 App-side CRecipeEditMgr receives & executes motion

Source/ALPHA (Direct Approach)

Source/ALPHA/DlgTestMode.cpp

1 Read recipe from CRecipeEditMgr directly
2 Calculate head positions in-process
3 Call CMaintControlMgr motion APIs directly
4 Immediate synchronous result & status update
Key difference: DLL version communicates via shared memory + Windows message (IPC). ALPHA version calls manager APIs directly (in-process). Both produce the same motor actions.

5 Test Mode - 4 Modes (Head Movement)

ModeHead AxesZ PositionMotion APIPurpose
0: Review Y1, Y2, X2 Z2 = ReviewZ
Z1 = SafetyZ2		 MoveCmdPosReview() Visual review position
1: WAD Y1, Y2, X2 Z2 = SpecZ
Z1 = SafetyZ2		 MoveCmdPosWAD() WAD measurement position
2: Vision Y3, Y4, X3 Z1 = QualityZ
Z2 = SafetyZ1		 MoveCmdPosVision() Vision inspection position
3: Angle Y1, Y2, X2 Z2 = AngleZ
Z1 = SafetyZ2		 MoveCmdPosAngle() Angle measurement position
2-Head Pairing Logic: Y1/Y2 (or Y3/Y4) are paired heads. If gap between adjacent cells > HeadGap, heads separate to two cells. Otherwise both heads converge on the same cell center.

6 DLL Shared Memory Data Packing

The dfcRecipe DLL packs all position data into VTM_RECIPE::m_sRunState shared memory, then signals the App via Windows message.

// S_RecipeRunState structure packing
m_dwData1 = M_CMD_TEST_MODE // Command ID (0x19)
m_dwData2 = 0=MOVE | 1=PRE_CONTACT | 2=CONTACT | 3=UNCONTACT
m_dwData3 = m_nTestMode // 0~3 (Review/WAD/Vision/Angle)

// fData[] — double precision position data
fData[0] = stick index    fData[1] = cell index
fData[2] = StageY        fData[3] = StageR (rotation)
fData[4] = CellX         fData[5] = CellY
fData[6] = Stick0 StageY  fData[7] = Cell count
fData[8] = ReviewZ       fData[9] = SpecZ
fData[10+] = All cell X positions (for 2-head pairing)

// nData[] — int precision (x1000 scaled)
nData[0] = QualityZ*1000   nData[1] = AngleZ*1000
nData[2] = OffsetY*1000    nData[3] = OffsetR*1000
nData[4] = HeadReviewY*1000
nData[5] = BackHeadGap*1000   nData[6] = FrontHeadGap*1000

// Signal to App
::PostMessage(m_hWnd, WM_RECIPE_EVENT, M_RCP_TEST_MODE, sub_cmd);
