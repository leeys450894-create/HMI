이어 검사 (Resume Inspection)

ALPHA HMI - Glass 검사 이어 검사 기능
일자: 2026-07-03 상태: Phase 1~5, 7 완료 작성자: LYS

1 개요

N-Stick 측정 루프 중 검사가 중단(NG, Cancel, 비정상 종료, 정전)되었을 때, 이어 검사(Resume Inspection) 기능은 Stick 단위로 진행 상황을 저장하여 다음 실행 시 중단 지점부터 검사를 이어서 수행할 수 있도록 합니다.

기존 (AS-IS)

Stick 30개 측정 진행 중
Stick 15에서 이상 발생으로 중단
다음 실행: Stick 0부터 처음부터 다시 시작

VS

변경 (TO-BE)

Stick 30개 측정 진행 중
Stick 15에서 이상 발생으로 중단
다음 실행: 이어 검사 팝업 → Stick 16부터 재개

2 자동 시퀀스 (9단계) 및 Resume 포인트

Resume 관련 단계가 하이라이트 표시됩니다. 각 단계의 Resume 동작이 태그로 표시됩니다.

[0] Adsorption Glass 진공 흡착
[1] Recipe 레시피 로드 + 결과 초기화(ResultClear) Resume: ResultClear 건너뛰기
[2] GlassAlign 패턴 서치, Theta/XY 보정
[3] ProbeAlign 프로브 패턴 매칭
[4] PreMeas PAD 서치, Contact, OST, R-Test
[5] AGING P1~P4 프로브 AGING
[6] Measure N-Stick 측정 루프 (핵심) Resume: LastStick+1 부터 시작
[7] Result 결과 저장, 판정
[8] Unload 안전 이동, CIM 통보

7 SystemConfig.ini 설정 옵션

[OPT_PARA]
USE_RESUME_INSPECTION=0    ; 0=OFF, 1=ON (Resume 기능 ON/OFF)
RESUME_EXPIRE_HOURS=0     ; 0=무제한, 24=24시간 후 자동 폐기

USE_RESUME_INSPECTION

  • 0 (OFF): 기능 비활성화, 기존 동작
  • 1 (ON): 검사 시작 시 Resume 체크 활성화

RESUME_EXPIRE_HOURS

  • 0: 만료 없음 (항상 이어 검사 가능)
  • N: N시간 후 Resume 정보 자동 폐기

안전성 확인

스레드 안전성

SetResumeMode()는 EngineStart() 전에 호출됨. 경합 조건 없음.

ResumeMode 플래그 생명주기

팝업에서 설정 → Step[1] Recipe + Step[6] Measure에서 사용 → 즉시 리셋. 잔류 없음.

빌드: 성공 (에러 0건)
한글 손상: 0건 (전체 파일 검증 완료)

Nullptr 안전성

모든 pResumeInfoMgr 사용처에서 nullptr 검사 확인.
