## 1. ACS 듀얼 컨트롤러 지원 (2026-07-13)

### 1.1 배경

OCP 설비는 ACS SPiiPlus 모션 컨트롤러를 **2대** 사용한다. 90개 축이 각각 다른 컨트롤러에 물리적으로 매핑되어 있으며, 기존 HMI는 단일 컨트롤러(`df_MAX_CTRL=1`)만 지원하여 OCP 환경에서 동작 불가.

### 1.2 설계 방향

- 각 축의 `axis_data_type` 구조체에 `m_iACSMap` (0 또는 1) 필드를 추가하여 해당 축이 어느 컨트롤러에 연결되어 있는지 식별
- 모든 `acsc_*` API 호출을 `m_hAcs[m_cAxis[nAxis].m_iACSMap]`으로 디스패치하여, 축별로 올바른 컨트롤러 핸들을 자동 선택
- INI 설정 파일에서 `ADDRESS` (컨트롤러 0 IP), `ADDRESS2` (컨트롤러 1 IP)를 읽어 각각 독립 연결

### 1.3 수정 상세

## 3. MakeCell rotate=0 Cell ID 불일치 수정 (2026-07-16)

### 3.1 문제 현상

Glass Rotation 옵션 `m_nGlsRotate=0` (Stage 90도 회전)으로 MakeCell 실행 후 자동 검사를 진행하면, Recipe에 저장된 Cell ID와 시퀀스 실행 시 생성되는 Cell ID가 불일치. `m_nGlsRotate=1` (Stage 0도)에서는 정상.

### 3.2 근본 원인 분석

**MakeCell 좌표 생성** (`MakeCellDlg.cpp:660`, 수정 전):
```cpp
// rotate 값에 관계없이 항상 동일한 공식
strCellID.Format(_T("%c%02d"), 65 + j, i + 1);
// j=Cell 인덱스 → 알파벳, i=Stick 인덱스 → 숫자
// 예: A01, B01, C01...
```

**시퀀스 실행** (`DoWorkGlassMeasureStep.cpp:MakeCellID`, line 128~137):
```cpp
if (iRotate == 1)  // 90도: 기존과 동일
    strCellId.Format(_T("%c%02d"), 65 + nCellNum, iStick + 1);
else               // 0도: 축 교차(transpose)
    strCellId.Format(_T("%c%02d"), 65 + nMaxStick - iStick - 1, nCellNum + 1);
```

rotate=1에서는 두 공식이 우연히 일치하지만, rotate=0에서는 알파벳/숫자 매핑이 완전히 다름.

### 3.3 수정 내용

`MakeCellDlg.cpp` line 653~676에 rotate 분기를 추가하여 시퀀스의 `MakeCellID`와 동일한 공식 적용:

```cpp
int nGlsRotate = g_inRcpInfo.GetGlsRotate();
nMaxStick = g_inRcpInfo.GetStickCount();

for (int i = 0; i < nMaxStick; i++) {
    for (int j = 0; j < g_inRcpInfo.GetCellCount(i); j++) {
        if (nGlsRotate == RCP_CELL_ANG_90) {
            // rotate=1 (YY, BT): Letter=CellIdx, Num=StickIdx+1
            strCellID.Format(_T("%c%02d"), 65 + j, i + 1);
        }
        else {
            // rotate=0 (DG): Letter=MaxStick-StickIdx-1, Num=CellIdx+1
            strCellID.Format(_T("%c%02d"), 65 + nMaxStick - i - 1, j + 1);
        }
        g_inRcpInfo.SetCellID(i, j, strCellID);
        g_inRcpInfo.SetCellArea(i, j, (i * g_inRcpInfo.GetCellCount(i)) + j);
    }
}
```

### 3.4 Cell ID 생성 예시 (3-Stick × 5-Cell)

| rotate | Stick(0) | Stick(1) | Stick(2) |
|--------|----------|----------|----------|
| **1 (90도)** | A01,B01,C01,D01,E01 | A02,B02,C02,D02,E02 | A03,B03,C03,D03,E03 |
| **0 (0도)** | C01,C02,C03,C04,C05 | B01,B02,B03,B04,B05 | A01,A02,A03,A04,A05 |

### 3.5 영향 범위

시퀀스 실행 코드(DoWorkGlassMeasureStep, DoWorkGlassAGINGStep 등)는 수정 불필요 — jsyoon 2022.09.29에 이미 올바르게 구현되어 있으며, 이번 수정은 MakeCell 쪽을 이에 맞춘 것.

**주의사항:** 기존 rotate=0으로 저장된 `.rcp` 파일은 Recipe Update(MakeCell) **재실행 필요** (Cell ID가 파일에 저장되므로).

## 4. nCellStatus 인덱싱 불일치 수정 — OST/RTEST/AGING (2026-07-16)

### 4.1 문제 현상

rotate=0 설정으로 자동 검사 진행 시, UI의 Cell 상태 그리드에서:
- OST(`df_CELLSTATE_OST_NOR`) / AGING(`df_CELLSTATE_AGING_START`) 표기 위치와
- WAD(`df_CELLSTATE_WAD_START`) / ANGLE(`df_CELLSTATE_ANGLE_START`) 표기 위치가 **서로 다른 열(Stick)에 표시**됨

### 4.2 근본 원인 분석

`nCellStatus[cellIdx][stickIdx]` 배열의 **두 번째 인덱스(stickIdx)** 산출 방식이 검사 유형별로 다름:

**WAD/ANGLE/VISION** (올바른 방식):
```cpp
// MakeCellID() 경유 — rotate=0일 때 변환 적용
nMeasStick = nMaxStick - iStick - 1;
nCellStatus[nCellNum][nMeasStick] = df_CELLSTATE_WAD_START;
```

**OST/RTEST/AGING** (수정 전 — 변환 누락):
```cpp
// m_nAgingStartStick[4]에 raw iStick 그대로 저장
m_nAgingStartStick[4] = iStick;  // 변환 없음!
// PG 통신에서 이 값을 그대로 사용
nCellStatus[i][iStick] = df_CELLSTATE_OST_NOR;
```

rotate=0에서 `iStick=0`인 경우:
- WAD: `nCellStatus[cell][nMaxStick-1]` (변환됨)
- OST: `nCellStatus[cell][0]` (raw) → **다른 열에 표기**

### 4.3 수정 내용

`m_nAgingStartStick[4]`에 값을 저장할 때, rotate=0이면 `MakeCellID`와 동일한 변환(`nStickCnt - iStick - 1`)을 적용:

**OST** (`DoWorkGlassMeasureStep.cpp` line 5320~5324):
```cpp
// LYS 2026-07-16 rotate=0: convert iStick to match MakeCellID nMeasStick
if (iRotate == 0)
    m_pShareItem->GetShareMemoryMgrPtr()->GetSharedMemory()->m_nAgingStartStick[4] = nStickCnt - iStick - 1;
else
    m_pShareItem->GetShareMemoryMgrPtr()->GetSharedMemory()->m_nAgingStartStick[4] = iStick;
```

**RTEST** (`DoWorkGlassMeasureStep.cpp` line 5418~5422):
- 동일 변환 로직

**AGING/OCP** (`DoWorkGlassMeasureStep.cpp` line 5497~5505):
```cpp
int iAgingStick = GetMeasureStick();
S_RecipeInfo* pAgingRcpInfo = m_pShareItem->GetRecipeEditMgrPtr()->GetRecipeInfo();
if (pAgingRcpInfo != nullptr && pAgingRcpInfo->m_sOptionItem.m_nGlsRotate == 0)
{
    S_RecipeData* pAgingRcpData = m_pShareItem->GetRecipeEditMgrPtr()->GetRecipeData();
    iAgingStick = (int)pAgingRcpData->m_vecStick.size() - iAgingStick - 1;
}
m_pShareItem->GetShareMemoryMgrPtr()->GetSharedMemory()->m_nAgingStartStick[4] = iAgingStick;
```

### 4.4 수정 후 인덱싱 일치 확인

rotate=0, `iStick=0`, `nMaxStick=5` 기준:

| 검사 | 수정 전 stickIdx | 수정 후 stickIdx | WAD와 일치 |
|------|-----------------|-----------------|-----------|
| OST | 0 | 4 (=5-0-1) | 4 ✓ |
| RTEST | 0 | 4 (=5-0-1) | 4 ✓ |
| AGING | 0 | 4 (=5-0-1) | 4 ✓ |
| WAD | — | 4 (MakeCellID) | 기준 |
